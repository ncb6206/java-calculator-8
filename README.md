# java-calculator-precourse

# 구현 사항
- [ ] 빈 문자열 또는 공백 입력 시 0을 반환한다. 
- [ ] 기본 구분자(쉼표 , 또는 콜론 :)로 분리된 양의 정수의 합을 계산한다. 
- [ ] 커스텀 구분자를 지원한다. 입력은 //{delimiter}\n 형식이며, 해당 구분자와 기본 구분자를 모두 허용한다. 
- [ ] 음수 또는 숫자가 아닌 값, 빈 토큰 등 잘못된 입력 시 IllegalArgumentException을 발생시킨다. 
- [ ] 입출력 형식: 프롬프트 덧셈할 문자열을 입력해 주세요. 출력 후 입력을 받고, 결과 : {합} 형식으로 결과를 출력한다. 
- [ ] 프로그램 진입점은 Application.main()이며, System.exit()를 사용하지 않는다.
